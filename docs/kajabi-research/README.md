## תקציר מנהלים

**מה Kajabi:** פלטפורמת "הכול במקום אחד" ליוצרי ידע. כוללת קורסים, Coaching, קהילה, פודקאסטים, ניוזלטרים, צ'קאאוט עם מונטיזציה עמוקה, אתר ובונה דפים, דיוור ואוטומציות, CRM, אנליטיקה ושכבת AI (Cofounder, Teaching/Sales Agents ו-MCP). המחיר הוא $179–$499 לחודש.

**במה הם הכי חזקים:**
1. **הפרדה בין Product ל-Offer.** אותו תוכן נמכר בכמה דרכים: Freemium דרך Paywall, חבילה, מנוי, תשלומים או מתנה.
2. **עומק בצ'קאאוט:** Order bumps, Upsell ו-Downsell ב-One-click, Scarcity, נטישת עגלה ו-Retention offer בביטול.
3. **הכול מחובר:** כ-45 טריגרים וכ-30 פעולות אוטומציה על אותו מאגר אירועים.
4. **בונה דפים מבוסס Schema** (Section, Block ו-Settings, בדומה ל-Shopify).
5. **AI שמחובר לתוכן עצמו:** Teaching Assistant בתוך כל שיעור.

**איך זה בנוי:**
- **Admin:** מונולית Rails עם Hotwire. מסכים אינטראקטיביים הם איי React שנטענים דרך Stimulus.
- **API פנימי:** JSON:API.
- **תבניות:** כל עמוד (אתר, דף נחיתה, נגן קורס, צ'קאאוט) הוא Theme ב-Liquid.
- **קהילה:** שירות Next.js נפרד מאחורי reverse proxy, עם מזהי UUID.
- **תשתית:** וידאו ב-Wistia, חיפוש ב-OpenSearch, עדכונים חיים ב-ActionCable, ומערכת העיצוב Pine (קוד פתוח).

**החולשות שהכי רלוונטיות לנו:**
- **אין עברית ואין RTL מלא.**
- **Kajabi Payments ו-Stripe לא זמינים לעסק ישראלי.** נשאר רק PayPal.
- אין חשבונית ישראלית, אין WhatsApp, ויש מטבע אחד להצעה.
- מחיר גבוה עם עמלות נסתרות.
- קהילה חלשה יחסית.

**ההמלצה ל-Bonded:** לא לבנות Kajabi שלם. כדאי לבנות את ה-20% שמייצרים 80% מהערך, על ה-Stack הקיים (Next.js 16, Supabase ו-Mux):
- **שלב 0:** לסגור את ההרשמה החופשית לכל קורס ואת בעיות ה-RLS.
- **שלב 1:** Offer, צ'קאאוט בעברית, סליקה ישראלית עם תשלומים, חשבונית אוטומטית, ומסכי Admin להזמנות ולתלמידים.
- **שלב 2:** מודולים ו-Paywall (Freemium), כמו שכבר הוגדר ב-Kajabi.
- **שלבים 3–5:** CRM ואוטומציות, אתגרי קהילה עם WhatsApp, ו-AI TA.

**לפני שמתחילים לבנות:** יש 5 החלטות פתוחות שממתינות לתשובה שלך. הן בסוף [05-build-plan.md](05-build-plan.md#10-החלטות-פתוחות-דורשות-תשובה-ממך).
